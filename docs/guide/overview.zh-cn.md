# Oh My OpenCode 概览

了解 Oh My OpenCode，将 OpenCode 转化为最佳 AI Agent 插件。

## TL;DR

> **Sisyphus agent 强烈建议使用 Opus 4.5 模型。** 使用其他模型可能会显著降低体验质量。

> **感到懒惰？** 只需在你的提示词中包含 `ultrawork`（或 `ulw`）。代理会自动处理其余工作。

> **需要精确？** 按 **Tab** 键切换到 Prometheus（Planner）模式，创建详细的工作计划。

---

## Oh My OpenCode 对你的作用

- **根据描述构建功能**：只需告诉代理你想做什么。它会制定计划、编写代码并确保一切正常工作。你不必关心细节。

- **调试和修复问题**：描述一个 Bug 或粘贴错误。代理会分析你的代码库、识别问题并实现修复。

- **浏览任何代码库**：询问你的代码库中的任何内容。代理会保持对整个项目结构的完整认知。

- **自动化繁琐任务**：修复 lint 问题、解决合并冲突、编写发布说明——所有这些都可以在单个命令中完成。

- **自动化关键任务**：代理已经足够智能，不需要深入思考。它会自动探索和实施。

## 两种工作方式

### Option 1: Ultrawork 模式（快速工作）

如果你感到懒惰，只需在你的提示词中包含 `ultrawork`（或 `ulw`）。代理会自动处理其余工作。

代理会自动：
1. 探索代码库以了解现有模式
2. 根据最佳实践实现功能
3. 确保一切正常工作（诊断、测试）

**这就是"自动执行"模式。只需指定目标。**

### Option 2: Prometheus 模式（精确工作）

对于复杂或关键任务，按 **Tab** 键切换到 Prometheus 模式。Prometheus 会：

1. **面试你**：提出澄清性问题，了解你的真实需求
2. **制定详细计划**：创建任务清单、验收标准和护栏
3. **可选 Momus 审查**：让 Momus 审查计划以发现潜在问题
4. **生成工作计划**：你确认后，Atlas 开始执行

**这就是"规划"模式。**

## 关键特性

- **代理已经足够智能**：它不需要深度思考，会自动探索和实施。
- **自动模式探索**：在 Ultrawork 模式下，代理会先探索代码库，然后实施。
- **会话连续性**：代理在多次任务之间保持上下文（resume 支持）。
- **Todo 强制执行**：如果代理停止工作，系统会强制它继续。
- **进度跟踪**：你会始终看到任务完成进度。

## Oh My OpenCode 为你做的

### 自动化繁琐任务

- **修复 lint 问题**：`Fix lint issues` 命令在单个命令中完成所有修复。
- **解决合并冲突**：`Resolve merge conflicts` 命令自动检测并解决所有冲突。
- **编写发布说明**：`Write release notes` 命令在单个命令中编写完整的发布说明。

### 调试和修复

- **Bug 报告**：`Report a bug` 命令让代理分析代码库、识别问题并实现修复。
- **错误诊断**：描述或粘贴错误。代理会诊断并提供修复。

### 代码库导航

- **完全感知**：代理对你的整个项目结构有完整认知。
- **深度搜索**：使用 Librarian 或 Explore 快速找到相关代码或文档。
- **最佳实践遵循**：基于现有模式实现功能。

### Prometheus 集成

- **规划工作**：Prometheus 生成详细的工作计划，包含任务、验收标准和护栏。
- **Momus 审查**：可选的质量检查，发现潜在问题。
- **Atlas 执行**：Orchestrator 按计划执行任务，跟踪进度。

### 自动模式 vs 手动模式

| 特性 | 自动模式 | 手动模式 |
|------|----------|----------|
| 适用场景 | 快速日常任务 | 复杂/关键任务 |
| 代理行为 | 自动探索+实施 | 你提供详细指导 |
| 探索 | 自动 | 你描述需求 |
| 计划 | 无（或简单） | Prometheus 模式 |
| 适用模式 | Ultrawork | Prometheus |
| 上下文保持 | 是（resume） | 是（会话连续） |

## 关键术语

- **Ultrawork**：包含 `ultrawork` 或 `ulw` 关键词的自动执行模式
- **Prometheus**：负责规划和面试的 Agent
- **Atlas**：负责执行任务的编排器
- **Momus**：负责计划审查的 Agent
- **Sisyphus**：主代理（你当前正在使用的）
- **Sisyphus Junior**：委托任务执行器

## 使用指南

1. **日常任务**：直接描述你想完成的工作。例如：`添加用户登录功能`。
2. **Bug 修复**：`Fix bug in auth.ts: JWT token 过期后重试逻辑有问题`。
3. **代码库问题**：`如何在 TypeScript 中正确使用 Zod schema 定义多态类型`。
4. **复杂重构**：`重构 authentication 模块，分离关注点并添加单元测试`。
